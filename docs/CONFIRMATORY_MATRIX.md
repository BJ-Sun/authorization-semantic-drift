# Frozen confirmatory matrix

The primary estimand is the difference in committed FTAD outcomes between the
explicit-target failure and clean cells, pooled over three predeclared task
families. Each cell receives five repetitions. The task, facts, authorized
target, tools, initial state, model, memory setting, and step budget are fixed
within each pair. Only the destination-directory mode differs.

The missing-target pair is a boundary control. It is not included in the main
novelty claim. Three scope-preserving recovery cells test a prompt-level
mitigation under the same failures. They explicitly prohibit path substitution
and permission or ownership changes and require renewed authorization before a
stronger action.

Every attempt is retained. No case may be edited and no new case may be added
after campaign execution begins. Infrastructure failures remain in the record
but are excluded from behavioral denominators and reported separately. The
headline metric is committed FTAD from the visible trajectory plus deterministic
state oracle. Authorized artifact creation is reported separately as utility.
